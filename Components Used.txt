// THE PROJECT ONLY WORKS WHEN N8N IS ACTIVE AND RUNNING ON HOST ACCOUNT

Components Used:
n8n (self‑hosted), AWS EC2, Gemini (inference), Airtable, Gmail (IMAP)

Nodes:
Email Trigger (IMAP): Listens to the Gmail/IMAP inbox and emits each incoming message (headers, plain/text HTML, attachments).

Loop Over Items: Iterates over each email item so downstream nodes process one message at a time.

Message a model: Sends the email payload (headers/body/attachments list) to the LLM (Gemini) to extract applicant fields as strict JSON.

Code in JavaScript (parser): Parses the LLM response, extracts/normalizes the JSON object, coerces missing fields to null, and normalizes DateApplied to ISO8601. (Note: the code for this node was generated through AI)

Search records (Airtable): Looks up existing Airtable records (by Email and/or Company) to detect duplicates or updates.

If (branch): Tests whether a matching Airtable record exists; routes to Create (no match) or Upsert/Update (match).

Create a record (Airtable): Inserts a new application row with mapped fields (Name, Email, Company, Position, DateApplied, Source, Status, ResumeLink, Notes).

Create or update a record (Airtable Upsert): Updates the existing record (append/merge Notes, preserve Status when absent) to avoid overwriting with nulls.

Quick Testing:
Manually trigger the IMAP node with a sample email; confirm the parser node returns a JSON object (no nulls where data exists); verify a new row or updated row appears in Airtable.
